# 🛒 E-Commerce Sales Dashboard

## 📖 Overview

Developed an interactive **E-Commerce Sales Dashboard** using Power BI to analyze sales, profit, quantity, customers, products, states, and payment methods. The dashboard provides a clear view of business performance through interactive KPIs and visualizations.

## ✨ Key Features

* 📈 KPI Cards for Amount, Quantity, Profit, and Average Order Value
* 🗺️ State-wise Sales Analysis
* 🛍️ Category-wise Quantity Analysis
* 📅 Monthly Profit Analysis
* 👥 Customer-wise Sales Analysis
* 💳 Payment Mode Analysis
* 🏆 Sub-Category-wise Profit Analysis
* 🎯 Interactive Quarter and State Filters
* 📊 Interactive and User-Friendly Dashboard

## 📊 Dashboard Insights

* Monitor total sales, quantity, and profit.
* Compare sales performance across different states.
* Identify the most popular product categories.
* Analyze monthly profit trends.
* Compare customer-wise sales performance.
* Understand customer payment preferences.
* Identify the most profitable sub-categories.
* Use filters to explore data by quarter and state.
